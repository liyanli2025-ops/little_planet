# 你那边的天空 · 可试玩原型

两个人、两颗独立星球。可旋转、缩放、进入小屋，体验天气变化、冰箱、做饭、留饭、吃饭、音乐、翻牌小游戏和生活手账。

## 推荐试玩路线

1. 选择“去对方那里”。
2. 打开“随身包”，把零食放入对方冰箱。
3. 选择“认真做一顿饭”，选“留给阿远”，做好后放上餐桌。
4. 点击右下角角色头像，切换为阿远。
5. 打开冰箱发现零食，进入小屋的餐桌吃饭。
6. 翻开个人手账和共同回忆册，查看准备、发现、吃完的连续记录。
7. 写一页私人手账，或在共同回忆册中添加纪念日。

## 当前范围

- 真实三维几何场景，通过 Three.js 渲染；拖动旋转、按钮缩放、点击家具。
- 两个演示角色、独立冰箱与食物、天气和装扮。
- 晴、雨、雪、夜晚是可手动切换的演示天气。
- 随身包赠礼、食材消耗、三种食谱、留饭和食用。
- 行为自动记录；未发现的礼物不会提前出现在接收方手账或共同回忆册中。
- 私人文字手账、共同回忆、纪念日、留言、珍藏、Markdown 导出。
- 一种庭院花盆装扮、合成音乐、翻牌小游戏。

这是单设备原型，不是正式双人在线服务。没有真实账号、真实天气、跨设备同步、推送提醒、自由建造、图片上传或原生手机安装包。“一起做”模拟共同活动，用来体验手账规则。

数据保存在当前浏览器的 localStorage。切换演示角色可以查看各自记录，不构成真正的账号权限。清除浏览器数据会丢失存档；重要文字可通过导出保存。部署域名与本地预览使用不同存档。

## 本地运行

在本目录运行：

    node server.mjs

然后访问 http://127.0.0.1:4173 。请通过 HTTP 服务访问，不要直接双击 HTML；原型使用 JavaScript 模块。
