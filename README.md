# 你那边的天空 · 可试玩原型

两个人、两颗独立星球。可旋转、缩放、进入小屋，体验天气变化、冰箱、做饭、留饭、吃饭、音乐、翻牌小游戏和生活手账。

## 推荐试玩路线

1. 选择“去对方那里”。
2. 打开“随身包”，把零食放入对方冰箱。
3. 选择“认真做一顿饭”，选“留给阿远”，做好后放上餐桌。
4. 点击右下角角色头像，切换为阿远。
5. 打开冰箱发现零食，进入小屋的餐桌吃饭。
6. 翻开个人手账和共同回忆册，查看准备、发现、吃完的连续记录。
7. 写一页私人手账，或在共同回忆册中添加纪念日。

## 球面探索更新（第二版）

- 星球改为完整球体，背面也有道路、树林与河岸。
- 草帽角色可以沿球面行走，脚下方向随所在位置变化。
- 点击地面自动寻路，方向键 / WASD 或屏幕方向按钮行走；拖动观察，滚轮 / 双指缩放。
- “靠近，跟随散步”和“拉远，看整颗星球”切换视角。
- “沿小路绕星球一圈”自动完成环星散步，并记录到手账。
- 点击小屋先走到门口，再进入；点击家具先走到旁边，再打开互动。
- 新增分层树冠、屋瓦、木框、草帽背包角色、河流、木桥、温室与野餐角。
- 模型仍为程序化原型，尚未达到参考图的成品美术精度。

## 当前范围

- 真实三维几何场景，通过 Three.js 渲染；拖动旋转、按钮缩放、点击家具。
- 两个演示角色、独立冰箱与食物、天气和装扮。
- 晴、雨、雪、夜晚是可手动切换的演示天气。
- 随身包赠礼、食材消耗、三种食谱、留饭和食用。
- 行为自动记录；未发现的礼物不会提前出现在接收方手账或共同回忆册中。
- 私人文字手账、共同回忆、纪念日、留言、珍藏、Markdown 导出。
- 一种庭院花盆装扮、合成音乐、翻牌小游戏。

这是单设备原型，不是正式双人在线服务。没有真实账号、真实天气、跨设备同步、推送提醒、自由建造、图片上传或原生手机安装包。“一起做”模拟共同活动，用来体验手账规则。

数据保存在当前浏览器的 localStorage。切换演示角色可以查看各自记录，不构成真正的账号权限。清除浏览器数据会丢失存档；重要文字可通过导出保存。部署域名与本地预览使用不同存档。

## 本地运行

在本目录运行：

    node server.mjs

然后访问 http://127.0.0.1:4173 。请通过 HTTP 服务访问，不要直接双击 HTML；原型使用 JavaScript 模块。

## 素材

三维场景为程序化几何。手账封面为 AI 生成插画。Three.js r170 使用 MIT 许可，详见 dist/vendor/LICENSE-three.txt。字体采用 Noto 字体远程加载，失败时使用系统中文字体。

## 第三版：天气与生活模型
雨天使用更明显的前景雨线，雪天使用飘雪与白色地表。天气仍由演示按钮切换，尚未连接实时天气服务。
新增户外搭建/收起帐篷、营地休息、双人并坐、长椅读书与翻页。帐篷状态保存在各自星球；露营与读书写入手账。另一位角色为本机动作演示，尚未联机。
冰箱、食物、灶台与饭菜为实时三维模型；冰箱开门、点选食物、拿取缩放动画、备料/下锅/蒸汽/装盘与库存逻辑连接。弹窗可拖动模型视角。操作按钮作为触屏与可访问性入口保留。
第三版通过独立 Chrome 的桌面及 390×844 触屏尺寸检查：天气切换、露营、并坐翻书、步行进屋、模型食用、三步做饭、成品食用；另验证库存减少、动画中关闭不扣库存、赠餐归属与未发现状态、刷新后存档、室内外活动面板清理。未捕获页面错误。真实手机硬件帧率与真实双人联网尚未验收。


## 第五版：泰迪熊与宠物
两位角色改为原创泰迪熊造型：小禾为浅奶油毛色、玫瑰外套和贝雷帽；阿远为蜂蜜棕毛色、蓝色牛角扣外套和砖红帽。角色切换及双人并坐都保留独立样貌，兼容行走、露营、持书和翻页。
每颗星球有自己的小狗（饼干 / 栗子），默认在门口休息。支持沿球面小路跟随、追逐并叼回球/飞盘、低头喂食和自动回家。完成玩耍/喂食后写入手账并保存计数，结束散步可留记录；宠物瞬时位置不跨刷新保留。
独立 Chrome 验证通过：桌面/390×844 手机布局、两种角色切换、双人持书翻页、小狗跟随及间距、两种玩具完整取回、喂食和自动回家、事件及存档更新。没有捕获页面错误。仍为本机角色演示，未提供跨设备联机。
