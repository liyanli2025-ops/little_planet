# 场景优先的交互约定

精简必须保留入口、内容、状态和出口。操作结果已能从模型或数据看见时，不再弹一段重复解释；需要用户采取行动的错误必须就地显示。

| 页面 | 入口 | 默认可见内容 | 返回方式 |
|---|---|---|---|
| 院子总览 | Logo 的星球入口、室内底部院子 | 时间、近似地名、温度/天气、3D 场景 | 底部小屋进入室内 |
| 小屋 | 底部小屋、房屋模型 | 当前楼层、上/下楼、右侧房间入口 | 底部同一位置改为院子 |
| 房间功能 | 右侧房间、家具模型 | 一层客厅、二层卧室分组 | 关闭回场景；家具详情返回房间 |
| 长椅 | 长椅模型、日常、书籍详情 | 自动打开所选/最近阅读书；无书时打开可添加的书架 | 关闭内容保持坐姿；点地面起身 |
| 单本书 | 书架、长椅 | 封面、书名作者、已知阅读信息、真实简介、换书/外部阅读 | 返回书架；换书保持当前场景 |
| 简介异常 | 同一本书内 | 加载、未提供、失败分别显示；失败有重试 | 不依赖全局 toast、不清空感想 |
| 音乐展开 | 未播放时右上音乐、播放时迷你唱片、唱片机 | 旋转封面 CD、歌名、歌手、进度、红心、播放、下一首、分享 | 收起回全局迷你唱片；关闭音乐退出播放器 |
| 音乐收起 | 从播放器收起 | 小封面、暂停/播放、下一首 | 点小封面展开；与展开控制互斥 |
| 手账 | 底部手账 | 记录与分类 | 编辑/回复/删除返回手账；关闭回场景 |
| 花园 | 日常、花园模型 | 作物、成熟时间和可执行操作 | 关闭回场景 |
| 露营/篮球/宠物 | 日常、场景模型 | 当前动作必要控制和退出 | 退出停止活动，不影响音乐 |
| 随身包/装扮/账号 | Logo 菜单 | 物品、可用装扮、账号状态 | 关闭回场景 |
| 天气设置 | 总览天气卡、日常天气 | 自动定位状态和备用城市选择 | 返回天气面板；关闭回场景 |

播放动画只旋转唱片内容，不旋转按钮命中区域；尊重系统减少动态效果设置。暂停后动画暂停，关闭面板不会暂停音频。

地名由服务器内 GeoNames 城市数据近似匹配，不依赖额外反向地理接口，不向地名服务发送坐标。相距较远时加“附近”；无法识别时明确提示。手动选城保留用户所选名称，旧“设备所在地”存档自动补全。数据库仍只保存约 0.1 度精度坐标。

阅读正文仍在微信读书打开；阿球展示接口提供的简介、进度和自己的感想。不能把没有简介当作成功空白，也不能用生成文案冒充书籍内容。
