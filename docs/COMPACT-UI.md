# 界面整理：场景优先

- Logo 打开星球菜单：自己/对方星球、回到院子、装扮、随身包、账号设置。
- 底部常驻仅小屋、手账；移除重复进屋按钮和账号头像入口。
- 方向/缩放默认收起，Logo → 探索工具中开启；点地面走动、拖动观察仍保留。
- 音乐常驻仅播放/暂停与下一首；右上音乐入口内的「歌曲与收藏」包含封面、红心、留歌、来源、刷新、添加、关闭。
- 长椅只显示看书/起身，不显示原创示例正文、虚构页码或未开放的双人并坐。真实书目可展开「这本书」打开外部阅读或记感想。
- 露营移除装饰文案与未开放联机按钮；宠物保留实际动作及当前状态；花园、篮球说明按需展开。
- 书架的同步状态、单书的进度/管理/感想分组折叠；隐私标记和保存错误保留。
- 日常面板删除装饰性便签、重复副标题和说明；手动天气折叠。账号同步/互访细节折叠。
- 正常保存成功不常驻屏幕；等待、离线、保存失败仍显示。
- 耳机耳罩与熊耳中心对齐，新增柔软垫层、接缝环、金属铰链和弧形头梁。

验证：42 项自动测试通过；桌面及 390×844 浏览器验证菜单、旅行、房间、音乐、长椅、耳机、工具与装扮。真实 QQ 音乐播放并跨功能持续；折叠后的读书感想已通过实际服务器保存验证。未在实体 iPhone 上测试。
