# 阿球 FM：QQ 音乐

音乐来源已改为 QQ 音乐官方 QMplayer 网页组件，不再要求 Jamendo Client ID。

## 使用

小屋 → 听音乐：显示歌曲封面、播放/暂停、下一首、红心、留给对方。
「添加 QQ 歌曲」接受官方 HTTPS 歌曲详情链接（songDetail/歌曲mid 或 songmid 参数），也支持直接填写歌曲 mid。暂不支持短分享链接、歌单链接或歌曲搜索。

「随心听」从两位住户加入的共同曲池随机播放，并非 QQ 全曲库推荐。首次只有一首经测试可播放的示例《九九八十一》，可以继续添加歌曲。红心收藏仅自己可见；配对后可以留歌并写入共同手账。旧来源的数据库记录保留，但不混入 QQ 播放队列。

部分歌曲不可播放，可能受登录、会员、地区或服务变化影响。播放器显示错误并保留「在 QQ 音乐打开」链接；不绕过权限，也不下载或永久保存音频地址。浏览器需要主动点击播放，关闭网页后的后台播放不保证。

## 技术与验证

官方说明：https://y.qq.com/m/api/open/index.html
官方播放器：https://y.gtimg.cn/music/h5/player/player.js
元数据通过组件使用的腾讯接口获取；封面由腾讯图片服务提供。SDK 按需加载，仅请求网页播放模式。

独立 Chrome 测试已验证示例音频时钟前进及封面解码。真实 iPhone / 微信内浏览器以及腾讯云到元数据服务的连通性仍需部署后验证。测试通过不代表所有歌曲均可播放，也不代表获得商业曲库授权。
