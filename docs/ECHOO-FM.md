# 阿球 FM / Jamendo

入口：进入小屋，点击唱片机／听歌，打开「阿球 FM」。原 QQ 音乐链接唱片仍可从「留歌唱片架」进入。

第一版提供：真实封面 URL、随机队列、播放／暂停、下一首、进度条、自动续播、收起后的迷你播放器、个人红心、给已配对住户留歌和共同手账记录。红心属于阿球账号，不写入 Jamendo 账号。

## 接通音乐

Jamendo 官方文档的公共测试 Client ID 在 2026-09-25 实测返回 Suspended Application（code 11），因此产品没有内置该测试凭证，也不把模拟歌曲当真实曲库。

1. 第一位住户到 https://devportal.jamendo.com/ 注册开发者账号。
2. 创建应用：名称 Echoo，网址填自己的阿球网址；说明是非商业、两人使用的音乐发现播放器。
3. 使用 Read only 计划，复制应用的 Client ID。
4. 回阿球 FM → 音乐设置 → 粘贴 Client ID → 验证并连接音乐。

只需设置一次；服务端调用一次单曲接口，验证成功才保存到 SQLite settings。不要填 Client Secret 或账号密码。后续用户不需要另外登录 Jamendo。凭证验证失败保留之前的配置。

应用应遵守 Jamendo API 条款及歌曲各自许可；界面显示音乐人、Jamendo 链接和可用的许可链接。当前定位非商业个人使用，不能假定免费接口覆盖未来商业运营或任何配乐用途。没有音频下载或离线曲库功能。

## 实现与存档

- 官方 GET https://api.jamendo.com/v3.0/tracks/ 提供歌曲、封面及音频地址。避开已失效的 radios/stream。
- 热门歌曲分批载入并随机排序，同组尽量不重复。初版不是学习用户喜好的推荐算法。
- 音频由手机直接访问平台，服务器只访问元数据。歌曲链接过期后重新查询；故障显示原因，不假装正在播放。
- `/api/fm`、`/api/fm/track` 需登录，写操作使用现有 Origin / CSRF 校验、版本号和幂等命令。音乐设置仅第一位住户可写。
- 新表 fm_tracks / fm_hearts / fm_gifts 随现有 SQLite 完整备份；收藏默认私人，分享必须配对。
- fm_tracks 是有界元数据缓存，热门列表缓存 10 分钟，播放地址至多缓存 5 分钟。没有在阿球服务器保存音频文件。
- 关闭播放器弹窗继续播放，退出账号停止。关闭网页或手机进入后台是否继续播放取决于浏览器，不承诺后台持续播放。

## 验证边界

自动化测试覆盖服务端授权、收藏隔离、分享幂等、错误保护；浏览器以模拟平台响应、封面、可解码 WAV 验证真实 audio 元素时钟、播放控制、自动续播、音源失败恢复及手机布局。没有使用用户凭证，没有验证真实 Jamendo 音源在腾讯云和用户手机网络中的可用性。
