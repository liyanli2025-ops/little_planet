# 两套小屋模型（2026-09-29）

已将独立的 Three.js 家具与建筑模型接入实际场景。

- 白熊：浅橡木、拱窗、窗边沙发、圆餐桌、梳妆台；左侧楼梯。
- 棕熊：胡桃木与橄榄绿、地垫与矮桌、唱片柜；二层长书桌、双椅、床边收纳；洗手间藏在远离右侧楼梯的后角。
- 同一份布局数据控制家具位置、点击停靠点、寻路、做饭、端菜、睡觉和上下楼。
- 共享的冰箱与餐桌锚点保留，原有库存、餐食、花瓶和双人同步无需迁移。
- 模型是轻量化手工几何方案，包含软垫、窗帘、布料、木纹与灯光；并非效果图的照片级复刻。

验证：115 项自动测试通过；390×844 手机视口与 1440×1000 桌面视口；两套小屋的做饭、端上桌、放冰箱、坐下、上下楼、睡觉与唤醒；斜侧面视角检查；无页面脚本错误。

布局维护：dist/home-layout.js 的 stops 为角色中心位置，rects 为家具占地区域，寻路额外留出 0.24 单位余量。dist/designed-home.js 中动态床被与柜门保留独立点击标签，静态家具按材质和功能合并网格。
