# 两套小屋模型（2026-09-29）

已将独立的 Three.js 家具与建筑模型接入实际场景。

- 白熊：浅橡木、拱窗、窗边沙发、圆餐桌、梳妆台；左侧楼梯。
- 棕熊：胡桃木与橄榄绿、地垫与矮桌、唱片柜；二层长书桌、双椅、床边收纳；洗手间藏在远离右侧楼梯的后角。
- 同一份布局数据控制家具位置、点击停靠点、寻路、做饭、端菜、睡觉和上下楼。
- 共享的冰箱与餐桌锚点保留，原有库存、餐食、花瓶和双人同步无需迁移。
- 模型是轻量化手工几何方案，包含软垫、窗帘、布料、木纹与灯光；并非效果图的照片级复刻。

验证：117 项自动测试通过；390×844 手机视口与 1280×1000 桌面视口；两套小屋的做饭、端上桌、放冰箱、坐下、上下楼、睡觉与唤醒；斜侧面视角检查；无页面脚本错误。

布局维护：dist/home-layout.js 的 stops 为角色中心位置，rects 为家具占地区域，寻路额外留出 0.24 单位余量。dist/designed-home.js 中动态床被与柜门保留独立点击标签，静态家具按材质和功能合并网格。

## 家具细化与窗外环境

- 增加厚窗套、护墙板、柜门框、窗帘杆与挂环、壁灯、玻璃淋浴间、办公椅、餐椅、圆软垫和编织地毯；白熊采用转角厨房及软包拱形床头。
- 窗外从当前星球的实际院子场景渲染，三个方向各使用 512×320 纹理；稳定时轮换刷新，楼层、星球、天气或昼夜变化时立即刷新。并非所在地的实景街景影像。
- 沿用星球主人环境数据：晴雨、阴云、雾霾、雪与夜色影响窗外；玻璃内有轻雨滴和雪花，室内日光随天气减弱，夜间保留暖灯。
- 室内增加轻量接触阴影与多重采样抗锯齿。物理手机 GPU 性能仍需线上设备反馈。
- 浏览器覆盖两种小屋的日间、雨雪、夜间及手机尺寸；确认窗户数据源为 planet，无脚本或着色器错误。厨房端菜/收纳、楼层切换、睡觉唤醒回归通过。
- 模型的布局、窗户和家具细节已进一步靠近参考图；材质仍是风格化实时渲染，不宣称达到效果图的写实质感。
