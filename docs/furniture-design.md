# 小屋家具与装饰

入口：房间菜单中的「布置小屋」，书桌保留原快捷入口。衣柜仍负责「设计新衣」。

分类共 19 种：
- 家具：沙发、茶几、边几、床头柜、矮凳、落地灯。
- 软装：地毯、靠垫、毯子、窗帘。
- 装饰：花器、托盘、相框、小摆件、挂画、挂钟。
- 植物：盆栽、大型绿植、垂吊绿植。

真实文字模型通过 edit_object 选择各类型的结构、尺寸及配色，浏览器生成标准三维结构；此流程不提交腾讯 3D 任务。预览后保存，支持继续修改、收起和历史恢复。未支持的结构应解释，不能声称完成。相框和挂画目前是内置构图，没有照片上传；新花器是装饰，现有餐桌花瓶仍负责插花。

餐桌/书桌每个支撑位一件；沙发允许一件靠垫加一件毯子；窗帘替换一层主窗的原窗帘。墙饰使用每层的安全墙面位置。服务器计算支撑面的高度和坐标并校验尺寸。地面家具新增时会寻找附近可通行的位置，修改位置时不擅自挪动。新增矮凳支持坐下，落地灯使用室内亮度入口。抽屉开合、自由拖拽、照片墙组合和其他大型功能家具不在本次范围内。

验证：furniture-catalog.test.mjs 覆盖结构尺寸、支撑位置、通道和非法参数；studio.test.mjs 使用模拟文字服务覆盖所有 19 类的预览、保存、修改和恢复，并确认不调用 3D 服务。浏览器检查手机和桌面入口、花器与矮凳的生成保存恢复以及坐下姿态。未使用生产 API Key 做本次在线模型测试。
