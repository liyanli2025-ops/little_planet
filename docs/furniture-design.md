# 小屋家具与装饰

入口：房间菜单中的「布置小屋」，书桌保留原快捷入口。衣柜仍负责「设计新衣」。

分类共 19 种：
- 家具：沙发、茶几、边几、床头柜、矮凳、落地灯。
- 软装：地毯、靠垫、毯子、窗帘。
- 装饰：花器、托盘、相框、小摆件、挂画、挂钟。
- 植物：盆栽、大型绿植、垂吊绿植。

真实文字模型通过 edit_object 选择各类型的结构、尺寸及配色，浏览器生成标准三维结构；此流程不提交腾讯 3D 任务。预览后保存，支持继续修改、收起和历史恢复。未支持的结构应解释，不能声称完成。相框和挂画目前是内置构图，没有照片上传；新花器是装饰，现有餐桌花瓶仍负责插花。

餐桌/书桌每个支撑位一件；沙发允许一件靠垫加一件毯子；窗帘替换一层主窗的原窗帘。墙饰使用每层的安全墙面位置。服务器计算支撑面的高度和坐标并校验尺寸。地面家具新增时会寻找附近可通行的位置，修改位置时不擅自挪动。新增矮凳支持坐下，落地灯使用室内亮度入口。抽屉开合、自由拖拽、照片墙组合和其他大型功能家具不在本次范围内。

验证：furniture-catalog.test.mjs 覆盖结构尺寸、支撑位置、通道和非法参数；studio.test.mjs 使用模拟文字服务覆盖所有 19 类的预览、保存、修改和恢复，并确认不调用 3D 服务。浏览器检查手机和桌面入口、花器与矮凳的生成保存恢复以及坐下姿态。未使用生产 API Key 做本次在线模型测试。

## Tiny Treats 真实植物

用户提供的 House Plants 1.0 FREE，作者 Isa Lousberg，CC0。精选 14 个 GLB（约 1.6 MB），许可证和各模型三角面数见 dist/assets/tiny-plants/。原始 glTF 经 glTF Transform prune/dedup 后转 GLB，保留原贴图和材质，无运行时外部下载依赖。

盆栽和大型绿植支持龟背竹、绿萝、虎尾兰、丝兰、金钱树、仙人掌、多肉；垂吊绿植支持绿萝。文字模型选择真实物种 variant、花盆 planter（陶土/灰色素盆）、位置与尺寸。tint 对花盆染色，白色保留原材质；叶片保持原色。现有旧款数据继续可用。未提供任意物种生成、方盆或任意花纹绘制。

尺寸为最大占地包围盒，整体等比例缩放，叶片不拉伸；实际高度可能小于指定上限。桌面与地面植物根部埋入土面、垂叶不穿过支撑面。模型按需加载，缓存字节但每份实例独立拥有渲染资源，换品种时旧加载不会覆盖新方案。失败可重试，未加载成功前不允许保存空白方案。

验证新增七种植物的文字工具输出→预览→保存→修改品种/花盆路径（模拟服务，不消耗真实接口额度）。浏览器验证全部植物大小两种形态的包围盒、模型请求失败/重试、桌面预览和保存刷新；截图为实际 GLB 渲染。

## 原有沙发替换

标准「沙发」固定替换每间小屋的一层窗边沙发，不提供另放第二张沙发的选项。初次替换用 create，或 move + builtin:sofa；兼容 lower.sofa 等既有定位名。已有替换款则复用该作品 id。服务器按当前小屋布局固定位置、楼层与朝向，仍校验尺寸和通道；不把陌生作品 id 或其他家具自动当作沙发。收起替换款会恢复原沙发。

回归：两种小屋均覆盖澄清后回复“直接换”、预览、保存、重启读取、继续改色和回滚；模拟文字服务，不调用线上接口。浏览器使用 Playwright（Browser plugin not available）验证手机对话、预览、保存刷新以及替换后坐下，无页面异常。
